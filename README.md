# VigiPlan Management System 🛡️

Solución web modular diseñada para la administración integral de personal y servicios de vigilancia en empresas de seguridad privada. El sistema permite centralizar la gestión operativa en un único panel de control, eliminando la complejidad y los errores humanos comunes en el uso de planillas tradicionales.

## 🚀 Características Principales

*   **Panel de Administración Total (CRUD):** Control absoluto y dinámico sobre Objetivos (clientes), Puestos específicos, Configuración de Turnos Horarios y legajos de Vigiladores.
*   **Motor de Asignación Inteligente (En desarrollo):** Proyección quincenal/mensual automatizada que respeta de forma estricta las regulaciones laborales (descanso mínimo de 12hs, límite de 6 días consecutivos trabajados, topes de horas extras).
*   **Control de Presentismo Mobile-Friendly:** Interfaz optimizada para que los encargados registren novedades, asistencias y ausencias en tiempo real mediante autenticación rápida por PIN.
*   **Historial de Cambios y Reportes:** Auditoría completa de modificaciones y exportación de métricas mensuales para facturación y liquidación.

## 🛠️ Stack Tecnológico
*   **Backend:** Node.js, Express
*   **Base de Datos:** MySQL / PostgreSQL
